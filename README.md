# DÉZEL Storefront

موقع متجر DÉZEL لعرض المنتجات وإتمام الطلبات.

## الملفات
- `index.html`: واجهة المتجر.
- `config.js`: إعداد Supabase العام (anon key).
- `supabase.sql`: مخطط قاعدة البيانات وتعريفات المتجر.

انشر محتويات المستودع على Vercel أو Netlify، وتأكد من تطبيق إعدادات قاعدة البيانات في Supabase.
